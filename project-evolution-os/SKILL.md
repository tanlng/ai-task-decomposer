# project-evolution-os

## 何时使用
- 推进项目
- 记录进度
- 下一步做什么
- 梳理当前阶段
- 提测
- 发布
- 日报
- 汇总当前开发状态

## 阶段约束
- 进入架构阶段后，默认按 `SDD -> DDD -> 开发准备` 推进。
- 未完成 SDD 的任务，不应标记为可开发，除非明确判断为无需系统设计的简单改动。
- DDD 不是所有任务必经步骤，但只要涉及核心规则归属、领域边界或可替换性，就必须补齐。

## 默认输出
1. 当前阶段
2. 当前子阶段
3. 当前状态
4. 下一步动作
5. 本轮成果物
6. 风险提醒
7. 状态更新建议
